# Дизайн-документ: «Война и Мир» — объединённая версия TSK + TPR

Собрано по: Wikipedia (TSK), knightsandmerchants.ru, kamclub.ru, KaM Remake Wiki, GameFAQs FAQ.
Цель — «последняя версия»: весь контент обеих частей в одном балансе.

## 1. Сюжетная рамка

- **TSK (20 миссий):** ~1200 год. Принц Лотар, блестящий полководец и наместник процветающей провинции,
  конфликтует с королём Каролусом (казнь рыцарей-разбойников → убийство эмиссаров → отказ сдать провинцию).
  Гражданская война, варвары давят с севера. Игрок — капитан дворцовой стражи, держит последнюю
  королевскую провинцию, подавляет мятеж.
- **TPR / «Вторая корона» (14 миссий):** спустя годы после гибели короля и наследника. Игрок помогает
  законному принцу вернуть корону через крестьянское восстание. + одиночные карты.

## 2. Интерфейс (1024×768, как в оригинале)

- **Главное меню:** пергамент, герб-щит, пункты: Новая игра (TSK / TPR / Своя карта), Загрузить,
  Сетевая (заглушка «в планах»), Настройки (скорость, туман, звук), Помощь, Выход.
- **Брифинг:** свиток с текстом советника + цели («постройте…», «уничтожьте…») + кнопка «В бой».
- **Игра:**
  - Верхняя полоса: меню (≡), скорость (⏸ x1 x2 x4 — F8 из TPR), игровое время, золото, еда (хлеб/колбаса/вино/рыба),
    стройматериалы (доски/камень), оружие-очередь.
  - Игровое поле: изометрия, ромб 64×32, 2 уровня высоты условно (холмы затемняются), туман войны.
  - Нижняя панель (высота ~168):
    - слева 176×176 — миникарта + кнопки слоёв (дороги/сети),
    - центр — вкладки: 🏠 Стройка | ⚒ Добыча | 🌾 Еда | ⚔ Война (категории зданий) + сетка 4×N кнопок,
    - справа — инфо: портрет/иконка, HP, профессия, приказ («Обеспечить продовольствием», «Штурм», «Стоп»),
      очередь школы/казармы, подсказки по цепочкам.
  - Сообщения: журнал слева вверху («Склад переполнен», «Житель умер от голода!», «Враг у ворот!»).
- **Горячие клавиши:** B — стройка, R — дороги, Space — пауза, F8 — ускорение, Del — снести, Esc — снять выбор.

## 3. Ресурсы (~28)

- **Сырьё (невосполнимые — камень/уголь/руды):** брёвна, камень, зерно, виноград/вино-сырец, уголь,
  железная руда, золотая руда, свинья (живая), шкура, рыба (TPR), лошадь (жеребёнок→взрослая).
- **Полуфабрикаты:** доски, мука, железо (слитки), золото (сундуки), кожа, свиное мясо (туша).
- **Еда:** хлеб, колбаса (1 мясо = 3 колбасы), вино, рыба. Хранится в харчевне/на складе.
- **Оружие/броня:** топор, лук, копьё, пика, меч, арбалет, деревянный щит, железный щит,
  кожаный доспех, железный доспех; осада: катапульта, баллиста (5 железа + 5 брёвен каждая).
- **Правило складов:** всё лежит только на складах; снёс склад — содержимое сгорело. Носильщики таскают по 1 шт.

## 5. Жители (голод!)

- Слуга (носильщик), строитель, каменотёс, лесоруб, столяр, крестьянин, пекарь, животновод,
  мясник, кожевник, шахтёр, плавильщик, кузнец, рыбак (TPR), рекрут.
- У каждого шкала сытости ~20–30 мин; проголодался → бросает работу → идёт в харчевню;
  нет еды → смерть. Солдаты сами не едят: только приказ «Обеспечить продовольствием» —
  слуги несут еду к отряду.
- Школа: золото → очередь жителей; рекруты → либо в башни, либо в казарму.

## 6. Армия

- **Пехота:** ополчение (топор), пехотинец, мечник (тяж.).
- **Кавалерия:** разведчик (лёгк.), рыцарь (тяж., требует лошадь+лучший комплект).
- **Стрелки:** лучник, арбалетчик (дальность, слабы в мелее).
- **Копейщики:** копейщик, пикинёр (бонус ×2.5 vs кавалерии).
- **Наёмники TPR (муниципалитет, только золото):** ополчение, бандит, бунтарь, сквайр, воитель, варвар.
- **Осада TPR:** катапульта (по зданиям), баллиста (по войскам).
- Экипировка пример: ополчение = топор+дер.щит; рыцарь = меч+жел.доспех+жел.щит+лошадь.
- Отряд 1–9 бойцов, строй: линия/колонна/каре; **в ближнем бою управление теряется**;
  **штурм** — короткий рывок пехоты (тоже без управления), перезарядка ~30 с.
- Контр-треугольник (множители урона): кавалерия ×1.6 vs стрелки/лёгкая пехота;
  копья ×2.2 vs кавалерия; тяж. пехота ×1.8 vs копья; стрелки ×1.5 vs пехота без щитов на дистанции.

## 7. ИИ (как в кампании оригинала)

Противник НЕ строит базу с нуля: у него декоративный город + выданные склады.
Он поддерживает армию, доедает еду, изредка докупает/дообучает и шлёт скриптованные волны.
Отсюда миссии двух типов: мирные (стройся → сноси базу) и боевые (только войско).

## 8. Кампании (34)

- TSK 1–20: обучение → экономика → оборона от варваров → штурм цитаделей Лотара.
- TPR 1–14: восстание, наёмники, осады, морские... нет, кораблей нет — только суша.
- Условия: мирная — снести казармы+склады+школы и всех солдат врага; боевая — перебить солдат.
  Поражение — потерял все склады (или всех солдат в боевой).

## 9. Технический маппинг на Godot

- Карта: `map_generator` (64×64…128×128), слои: grass/forest/stone/coal/iron/gold/water/fertile.
- Рендер: `world.gd::_draw()` — ромбы; здания/юниты — Node2D-фишки с процедурной отрисовкой
  (позже заменить на спрайты; оригинальные не коммитим по копирайту).
- Симуляция: тики 100 мс; носильщики — агентная очередь задач; производство — таймеры из game_data.
- Сохранения: JSON слепка GameManager (здания/юниты/склады/время/миссия).
