# Война и Мир — KaM Remake (TSK + TPR) на Godot 4

Фанатский ремейк **Knights and Merchants: The Shattered Kingdom** («Война и Мир», 1998, Joymania)
+ дополнение **The Peasants Rebellion** («Вторая Корона», 2002) — как «последняя версия»: общее дерево зданий,
юнитов и ресурсов обеих частей в одном проекте.

> Статус: играбельный каркас. Экономика, стройка по дорогам, голод, школа/казармы, отряды с потерей управления
> в бою, кампании 20 + 14 миссий, ИИ-декоратор, сейвы, ускорение F8 из TPR.

## Как запустить

1. Установи **Godot 4.2+** (ветка GL Compatibility — потянет и слабое железо, как оригинал на Pentium 133).
2. Клонируй репозиторий:
   ```sh
   git clone https://github.com/superpirov/kam-remake.git
   ```
3. Открой папку как проект в Godot → `F5` (запуск `scenes/main.tscn`).
4. Управление как в оригинале:
   - **ЛКМ** — выбор / приказ строить / точка сбора,
   - **ПКМ** — приказ отряду / отменить призрак здания,
   - **колесо** — зум камеры, **WASD / стрелки / СКМ-драг** — панорама,
   - **F8 / кнопки x1 x2 x4** — ускорение (нововведение TPR),
   - **Пробел** — пауза, **B** — меню стройки, **Esc** — меню.

## Что внутри (соответствие оригиналу)

| Система | Как в оригинале |
|---|---|
| Вид | Изометрия (ромбы 64×32), туман войны опционально, миникарта 176×176 снизу слева |
| Интерфейс | Нижняя панель во всю ширину: миникарта → вкладки стройки → инфо-панель; верхняя — ресурсы и меню |
| Экономика | Непрямое управление: слуги-носильщики таскают всё по дорогам, только через склад |
| Голод | У каждого жителя шкала сытости; мирные бросают работу и идут в харчевню, солдатам везут еду по приказу «Обеспечить продовольствием» |
| Школа → Казармы | Рекруты учатся в школе за золото, потом в казарме экипируются оружием/бронёй/лошадьми |
| Бой | Отряд в ближнем бою **теряет управление**, пехота умеет в **штурм-рывок**, треугольник: кавалерия бьёт стрелков/пехоту → копья бьют кавалерию → тяжёлая пехота рубит копья |
| Поражение/победа | Мирная миссия: снести врагу казармы+склады+школы и всех солдат; потерял все свои склады — поражение |
| TPR-новое | Рыба и хижина рыбака, муниципалитет с 6 наёмниками за золото, осадная мастерская (катапульта/баллиста), ускорение времени |

Полная спецификация: [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md).

## Структура проекта

```
scenes/            — main.tscn (меню→брифинг→мир), world.tscn, hud.tscn, unit.tscn, building.tscn
scripts/
  data/game_data.gd      — все здания/юниты/ресурсы/цепочки/кампании TSK+TPR (баланс оригинала)
  data/campaigns.gd      — 34 миссии: брифинги, стартовые склады, волны ИИ
  core/game_manager.gd   — автозагрузка: состояние, скорость, пауза, условия победы
  core/economy.gd        — носильщики, производство по таймерам, голод, харчевня
  core/military.gd       — отряды, формации, автобой, контр-юниты, штурм, башни
  core/map_generator.gd  — процедурная карта (лес/камень/уголь/железо/золото/рыба/плодородность)
  core/ai_director.gd    — ИИ-декоратор как в кампании: живёт на выданных ресурсах, держит армию, шлёт волны
  core/save_manager.gd   — сейвы в user://saves/*.json
  core/audio_manager.gd  — процедурный звук (WebAudio... то есть AudioStreamWAV-синтез): фанфары, стройка, мечи
  world/world.gd         — изометрический рендер ромбами, дороги, туман, выбор
  world/building.gd unit.gd serf.gd
  ui/main_menu.gd hud.gd build_menu.gd minimap.gd briefing.gd
```

## Дорожная карта

- [x] Каркас Godot 4, меню в стиле оригинала (пергамент/герб), HUD 1:1 по компоновке
- [x] Данные: 28 зданий, 25+ юнитов, ~28 ресурсов, цепочки (доски, хлеб, свиньи→колбаса+кожа, железо, золото)
- [x] Процедурные карты + редактор-подобная генерация под каждую миссию
- [x] ИИ волн + условия победы/поражения
- [ ] Настоящие спрайты в стиле оригинала (сейчас — процедурные иконки-заглушки; оригинальные ассеты под копирайтом, не коммитим)
- [ ] Сетевая игра (KaM Remake-style лобби)
- [ ] Редактор карт

## Про оригинал

- TSK: 20 миссий (14 мирных + 6 боевых), ~1200 год, мятеж принца Лотара против короля Каролуса.
- TPR: 14 миссий + одиночные карты; новое: рыба/рыбак, муниципалитет (ополчение, бандиты, бунтари, сквайры, воители, варвары), катапульты/баллисты.
- Источники: Wikipedia «Knights and Merchants: The Shattered Kingdom», kamclub.ru, knightsandmerchants.ru, KaM Remake Wiki, GameFAQs FAQ ReyJavikVI.
